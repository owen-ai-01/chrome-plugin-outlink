# 外链发现与评论辅助插件

Manifest V3 Chrome 扩展，用于从 Ahrefs/Semrush 或 CSV 数据中整理外链机会，筛选博客评论候选，并在人工审核后填写、提交评论。

> 默认工作流是“发现 → 检测 → AI 生成 → 自动填表 → 人工检查 → 提交”。插件不会绕过登录、验证码或站点权限。请只在允许评论且内容相关的页面使用。

## 安装

1. Chrome 地址栏打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `D:\code\chrome-plugin-outlink`。
5. 固定工具栏中的 **Outlink Collector**。点击图标会打开 Side Panel。
6. 修改代码后，在扩展卡片点击“重新加载”，并刷新已经打开的网页。

## 第一次配置

1. 打开插件的“固定URL发布”页。
2. 填写 OpenRouter API Key。
3. 模型可保留默认值，或换成 OpenRouter 当前可用的兼容模型。
4. 点击“保存配置”。
5. 打开“自动博客外链”页，填写推广网站名称、URL、主题关键词、评论作者名和邮箱。
6. 点击“保存配置”。首次使用不要勾选自动提交。

API Key 保存在本机 `chrome.storage.local` 中。导出的 JSON 完整备份会包含配置和 API Key，请妥善保管，不要公开分享。

## 方法一：从 Ahrefs 收集

1. 先在 Chrome 登录 Ahrefs。
2. 打开插件“收集”页，输入要分析的竞品域名。
3. 点击“开始收集”。插件会打开 Ahrefs Backlink Checker。
4. 等待 Ahrefs 表格加载；插件会读取当前账号可见的数据并尝试翻页。
5. 回到 Side Panel 查看统计和资源表。
6. 可用“仅看非 SPAM”和“仅看免注册博客评论候选”缩小范围。

## 方法二：从 Semrush 收集

1. 先登录项目配置的 Semrush 页面。
2. 打开“Semrush自动外链”。
3. 输入竞品域名并点击“打开 Semrush 并采集”。
4. 页面数据加载后，插件会接收可见页面/网络响应中的候选 URL。
5. 点击“刷新待发清单”，查看过滤后的博客或社区候选。

页面结构或账号权限变化可能导致自动采集失效。此时优先从平台导出 CSV，再使用插件导入。

## 方法三：导入文件

- 支持插件完整备份 `.json`。
- 支持 `.csv`、`.tsv`、`.xlsx` 和 `.xls` 资源表，可一次选择多个文件。
- 表格至少需要 URL 列；常见字段包括 URL、Domain、DR、Traffic、SPAM、博客评论、免注册候选。
- 点击顶部“导入备份”选择文件。

插件顶部“导出XLSX”导出资源列表；“导出JSON”导出完整数据和配置。

## 推广项目、模板和任务队列

1. 在“推广项目”中新增一个或多个推广网站，每个网站可独立设置名称、URL、关键词、作者和邮箱。
2. 同页设置基础间隔、随机延迟、每日上限、每域名上限以及黑白名单。
3. “模板”页提供 50 条英文内置模板，也可创建、编辑、导入和导出自定义模板。变量包括 `{siteName}`、`{siteUrl}`、`{keyword}`、`{date}`、`{year}`。
4. 在“任务队列”中选择推广项目，通过关键词、DR、资源类型、链接属性和发现时间过滤资源。
5. 勾选资源并点击“加入审核队列”。已发布资源、黑名单以及超过域名/每日上限的项目会被跳过。
6. 点击“打开下一条并填表”。队列采用逐条审核方式，不会绕过验证码或无人值守群发。

## 定时采集

1. 在“推广项目”的发布策略区域勾选“启用定时采集”。
2. 填写间隔小时数和竞品域名，每行一个。
3. 保存策略。Chrome 会按周期在后台打开一个 Ahrefs Backlink Checker 标签页。
4. 定时采集要求 Chrome 正在运行，Ahrefs 登录状态有效，并且页面结构仍受当前适配器支持。

## Google Sheets 同步

1. 创建一个 Google Sheet，然后进入“扩展程序 → Apps Script”。
2. 将仓库中的 `google-apps-script.gs` 内容粘贴到 Apps Script。
3. 点击“部署 → 新建部署 → Web 应用”。执行身份选择你自己，并按你的安全需要选择访问范围。
4. 完成 Google 授权后复制以 `/exec` 结尾的 Web App URL。
5. 在插件“统计与同步”中填入该 URL 和资源工作表名称，保存后点击“立即同步”。
6. 插件会同步资源、PostingLogs 和 TargetSites。同步属于向你配置的第三方端点传输数据，因此按钮会再次确认。

## 审核式发布评论（推荐）

1. 在资源表或候选表中先打开一个页面，确认文章与你的网站主题相关。
2. 保持该文章标签页为当前活动页。
3. 打开插件“自动博客外链”。
4. 点击“检测当前页”。插件会报告：
   - 评论系统；
   - 是否有 Website 字段；
   - 是否有验证码；
   - 是否要求登录；
   - 建议审核、人工处理还是跳过。
5. 点击“按当前文章生成”。AI 会根据文章标题和正文生成相关评论，并避免在正文硬塞网址。
6. 人工阅读和修改评论，确保内容真实、有帮助、不冒充实际体验。
7. 点击“预填当前页”。插件会填写评论、姓名、邮箱和 Website 字段。
8. 在网页中再次检查所有字段。
9. 手动点击网页提交按钮；也可以回到插件点击“一键提交”，插件会再次要求确认。
10. 在“发布”页查看记录，之后可点击“检查链接存活”。“已尝试提交”不等于评论已经公开，审核中的评论需要稍后复查。

## 从候选清单打开

1. 在“自动博客外链”候选表点击“打开写评论”，或在 Semrush 清单点击“智能填表发布”。
2. 插件打开目标页面，并使用当前评论草稿自动填表。
3. 若评论框位于 iframe 或需要点击 Reply，插件会尝试找到对应表单。
4. 检测到验证码或登录要求时会停止自动填写/提交，改由人工处理。

如果勾选自动提交，每次点击“打开并自动写评论”时仍会出现单页确认。该选项不用于无人值守批量群发。

## 状态与数据

- 收集、资源、发布记录和日志保存在本机浏览器。
- “发布”页保存填表/提交状态和截图。
- “日志”页展示采集、生成和发布错误。
- 卸载扩展通常会删除扩展本地数据，因此请定期导出 JSON 备份。
- “重置数据”会清除插件全部本地数据，操作不可撤销。

## 常见问题

### 检测不到评论区

刷新网页后重试。某些评论区延迟加载、位于跨域 iframe、已关闭、仅登录可见，或不属于当前支持的 WordPress/Disqus/Commento/通用表单结构。

### 填写了评论但没有 Website

该站可能不提供网址字段。这种情况下评论本身通常不会形成网站链接，不建议为了放链接而把 URL 硬塞进正文。

### 提交后看不到评论

常见原因是等待审核、反垃圾系统拒绝、重复评论、会话过期或表单验证失败。插件记录的是提交尝试，不能保证站长公开评论。

### Ahrefs/Semrush 没有抓到数据

确认已登录、页面表格已加载、插件已重新加载且网页已刷新。平台页面变化时使用 CSV 导入最稳定。
