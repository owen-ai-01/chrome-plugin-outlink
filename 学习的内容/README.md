# SEMrush 外链采集 Chrome 插件

## 项目简介

这是一个 Chrome 浏览器插件，用于自动采集 SEMrush 平台上的外链数据，帮助 SEO 人员快速收集和分析竞争对手的外链信息。

## 主要功能

### 1. SEMrush 数据采集
- 自动识别 SEMrush 外链分析页面
- 一键采集当前页面所有外链数据
- 支持分页自动翻页采集
- 智能解析外链表格数据

### 2. 外链数据提取
- **外链 URL**：目标网站的反向链接地址
- **锚文本**：链接使用的锚文本内容
- **域名权重**：来源域名的权威度（Authority Score）
- **页面权重**：来源页面的权重分数
- **链接类型**：Follow/Nofollow 属性
- **首次发现时间**：SEMrush 首次检测到该链接的时间
- **最后检测时间**：最近一次检测的时间
- **流量预估**：来源页面的预估流量

### 3. 自动发布功能
- 自动识别页面评论区/留言区
- 智能检测可发布的输入框
- 自动填充预设文字内容
- 支持多种评论模板
- 随机选择模板（避免重复）
- 自动点击发布按钮
- 发布成功/失败检测
- 发布记录追踪

### 4. 内容模板管理
- 预设多种评论模板
- 支持变量替换（网站名、关键词、日期等）
- 模板分类管理
- 自定义模板编辑器
- 模板随机化功能
- 支持导入/导出模板

### 5. 发布策略
- 自定义发布间隔时间
- 随机延迟（模拟真实用户）
- 发布频率限制
- 黑名单/白名单管理
- 自动跳过已发布页面
- 批量发布任务队列

### 6. 数据管理
- 实时显示采集进度
- 去重处理（自动过滤重复链接）
- 数据分类存储（按域名、日期等）
- 本地数据持久化存储
- 发布历史记录

### 7. 数据导入
- 支持导入 CSV 格式文件
- 支持导入 Excel 格式文件（.xlsx/.xls）
- 支持导入 JSON 格式文件
- 智能字段映射（自动识别列名）
- 数据验证与清洗
- 批量导入多个文件
- 导入数据与采集数据自动合并

### 8. 数据导出
- 导出为 CSV 格式（Excel 兼容）
- 导出为 JSON 格式（便于程序处理）
- 导出为 Excel 格式（.xlsx）
- 自定义导出字段选择
- 批量导出多个项目数据

### 9. 数据筛选与过滤
- 按域名权重筛选
- 按链接类型过滤（Follow/Nofollow）
- 按时间范围筛选
- 按关键词搜索
- 自定义高级过滤规则

### 10. 数据统计分析
- 外链总数统计
- Follow/Nofollow 比例
- 域名权重分布图表
- 锚文本词云分析
- 时间趋势分析
- 发布成功率统计
- 各平台发布数量统计

### 11. 用户界面
- 简洁的弹出窗口（Popup）界面
- 实时采集状态显示
- 数据预览表格
- 详细的配置页面（Options）
- 采集历史记录查看

## 技术栈

- **前端框架**: HTML5 + CSS3 + JavaScript (ES6+)
- **UI 框架**: 原生 JavaScript / 可选轻量级框架
- **数据解析**: DOM Parser / Cheerio
- **存储**: Chrome Storage API (sync + local)
- **数据处理**: Papa Parse (CSV) / SheetJS (Excel)
- **图表**: Chart.js / ECharts（可选）
- **构建工具**: Webpack / Vite

## 安装方法

1. 克隆或下载本项目
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目文件夹

## 使用说明

### 快速开始
1. 登录 SEMrush 账号
2. 进入任意域名的 Backlinks（外链分析）页面
   - 例如：`https://www.semrush.com/analytics/backlinks/overview/?searchType=domain&target=example.com`
3. 点击浏览器工具栏的插件图标
4. 点击"开始采集"按钮
5. 等待采集完成，查看采集结果

### 高级功能
- **自动翻页**：在设置中开启自动翻页，可采集多页数据
- **数据过滤**：设置筛选条件，只采集符合要求的外链
- **定时采集**：设置定时任务，自动采集指定域名的外链
- **批量导出**：选择多个采集任务，批量导出数据

### 数据导入
1. 点击插件图标打开弹出窗口
2. 点击"导入数据"按钮
3. 选择要导入的文件（CSV/Excel/JSON）
4. 系统自动识别字段并映射
5. 确认导入，数据将添加到本地数据库
6. 支持的文件格式：
   - CSV 文件（.csv）
   - Excel 文件（.xlsx, .xls）
   - JSON 文件（.json）

### 自动发布
1. 在插件中导入或采集外链列表
2. 进入设置页面，配置评论模板
3. 设置发布策略（间隔时间、频率限制等）
4. 访问外链列表中的网站
5. 插件自动检测评论区
6. 点击"自动发布"按钮
7. 插件自动填充内容并发布
8. 查看发布记录和统计

### 模板设置
1. 进入设置页面
2. 点击"模板管理"
3. 添加或编辑评论模板
4. 使用变量：`{网站名}` `{关键词}` `{日期}` 等
5. 保存模���
6. 示例模板：
   ```
   很不错的文章，学到了很多！推荐大家也看看 {网站名}
   感谢分享，{网站名} 也有类似的内容
   {日期} - 来自 {网站名} 的读者
   ```

### 数据导出
1. 在弹出窗口中查看采集的数据
2. 点击"导出"按钮
3. 选择导出格式（CSV/JSON/Excel）
4. 选择保存位置
5. 数据将自动下载到本地

## 注意事项

⚠️ **重要提示**：
- 需要有效的 SEMrush 账号才能使用采集功能
- 请遵守 SEMrush 的服务条款和使用规则
- 建议合理控制采集频率，避免对 SEMrush 服务器造成压力
- **自动发布功能请谨慎使用**：
  - 请遵守各网站的使用规则和服务条款
  - 合理设置发布频率，避免被识别为垃圾信息
  - 建议发布有价值的评论内容，而非纯广告
  - 某些网站可能有反机器人机制，请注意
- 采集的数据仅供个人学习和研究使用
- 请勿将采集的数据用于商业用途或二次销售
- 本插件不存储任何账号密码信息

## 适用场景

### 数据采集场景
- **竞品分析**：分析竞争对手的外链策略
- **外链建设**：寻找高质量的外链资源
- **SEO 审计**：评估网站的外链质量
- **内容营销**：发现潜在的内容发布平台
- **链接监控**：追踪外链的变化趋势

### 自动发布场景
- **外链建设**：在相关博客/论坛发布外链
- **品牌推广**：在目标网站留下品牌信息
- **流量引导**：通过评论引导流量到自己网站
- **社交互动**：批量参与社区讨论
