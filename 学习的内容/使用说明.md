# 博客外链助手 - 使用说明

## 一、安装插件

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 并回车
2. 开启右上角的 **「开发者模式」** 开关
3. 点击 **「加载已解压的扩展程序」**
4. 选择插件所在文件夹（`backlink` 目录）
5. 安装成功后，浏览器工具栏会出现插件图标 🔗

---

## 二、首次配置

安装后会自动打开设置页面，请先完成基础配置：

1. 点击插件图标 → 右上角 ⚙️ 按钮，进入设置页面
2. 填写 **网站名称**（用于评论模板中的 `{网站名}` 变量）
3. 填写 **网站 URL**（用于模板中的 `{网站URL}` 变量）
4. 填写 **主要关键词**（用于模板中的 `{关键词}` 变量）
5. 点击 **「💾 保存设置」**

---

## 三、采集外链（SEMrush）

### 步骤

1. 登录 [SEMrush](https://www.semrush.com)
2. 进入任意域名的外链分析页面，例如：
   ```
   https://www.semrush.com/analytics/backlinks/?searchType=domain&target=example.com
   ```
3. 等待页面数据加载完成（表格出现后）
4. 点击浏览器工具栏的插件图标
5. 在 **「📥 采集」** Tab 中，可以看到页面被识别为 **「✅ SEMrush 外链分析页」**
6. 选择采集方式：
   - **「采集当前页」**：只采集当前显示的这一页数据
   - **「自动翻页采集」**：自动翻页，采集所有页面数据（最多20页）
7. 等待进度条完成，提示采集成功

### 注意事项

- 需要已登录 SEMrush 账号
- 确保页面数据已完全加载后再点击采集
- 自动翻页采集时间较长，请耐心等待

---

## 四、导入外链文件

如果你已有外链数据文件（从 SEMrush 手动导出或其他来源），可以直接导入：

### 支持格式

| 格式 | 说明 |
|------|------|
| `.csv` | 逗号分隔文件，Excel 可直接打开 |
| `.json` | JSON 格式数据文件 |

> ⚠️ Excel `.xlsx` 文件请先在 Excel 中另存为 `.csv` 格式后再导入

### 导入步骤

1. 点击插件图标，进入 **「📥 采集」** Tab
2. 在 **「📂 导入外链文件」** 区域：
   - **方式一**：直接将文件拖拽到虚线框内
   - **方式二**：点击 **「选择文件」** 按钮，选择文件
3. 支持同时选择多个文件批量导入
4. 导入完成后会提示新增条数

### CSV 文件格式要求

CSV 文件第一行为列头，支持以下列名��自动识别）：

```
URL, Anchor Text, Domain Score, Page Score, Link Type, First Seen, Last Seen, Traffic
```

中文列名也支持：

```
外链, 锚文本, 域名权重, 页面权重, 链接类型, 首次发现, 最后检测, 流量
```

## 五、管理外链列表

点击插件图标，切换到 **「🔗 外链」** Tab：

### 搜索与过滤

- **搜索框**：输入关键词，实时过滤 URL 或锚文本
- **链接类型**：筛选 DoFollow / NoFollow
- **发布状态**：筛选 待发布 / 已发布 / 失败

### 导出数据

1. 点击 **「导出」** 按钮
2. 自动下载 CSV 文件（文件名含日期）
3. 导出的是当前过滤后的数据

### 清空数据

点击 **「清空」** 按钮，确认后删除所有外链数据（不可恢复）

## 六、自动发布评论

### 前提条件

- 已有外链数据（采集或导入）
- 已配置评论模板（设置页面）
- 当前页面有评论区

### 发布步骤

1. 打开目标博客文章页面（有评论区的页面）
2. 点击插件图标，切换到 **「🚀 发布」** Tab
3. 查看 **「当前页面」** 检测结果：
   - ✅ 绿色：检测到评论区，可以发布
   - ⚠️ 黄色：未检测到，可点击「重���检测」
4. 在 **「📝 评论模板」** 下拉框中选择模板
   - 模板内容会自动填入文本框，可手动修改
5. 在 **「🔗 选择外链」** 下拉框中选择要发布的外链 URL
6. 点击 **「🚀 自动发布」** 按钮
7. 插件会自动：
   - 滚动到评论区
   - 填入评论内容（含外链）
   - 点击提交按钮
8. 发布结果会显示在 **「📋 发布记录」** 中

### 发布记录

- ✅ 绿色：发布成功
- ❌ 红色：发布失败（可能原因：需要登录、验证码等）

## 七、模板管理

在设置页面的 **「📝 模板管理」** 中管理评论模板：

### 内置模板

插件预置了4个模板，可直接使用：
- 通用推荐
- 感谢分享
- 资源推荐
- 简短评论

### 添加自定义模板

1. 点击 **「+ 添加模板」**
2. 填写模板名称
3. 填写模板内容，可使用以下变量：

| 变量 | 说明 | 示例 |
|------|------|------|
| `{网站名}` | 你的网站名称 | 我的博客 |
| `{关键词}` | 主要关键词 | SEO优化 |
| `{网站URL}` | 网站地址 | https://example.com |
| `{日期}` | 当前日期 | 2024/3/13 |
| `{年份}` | 当前年份 | 2024 |

4. 右侧实时预览替换效果
5. 点击 **「保存」**

### 模板示例

```
很不错的文章，学到了很多！推荐大家也看看 {网站名}，有更多关于{关键词}的精彩内容。
```

## 八、发布策略设置

在设置页面的 **「🚀 发布策略」** 中配置：

| 设置项 | 说明 | 建议值 |
|--------|------|--------|
| 发布间隔时间 | 每次发布后等待的毫秒数 | 2000ms 以上 |
| 随机延迟 | 在间隔基础上随机增加延迟 | 建议开启 |
| 最多采集页数 | 自动翻页时的最大页数 | 10页 |
| 随机选择模板 | 发布时随机使用不同模板 | 建议开启 |
| 黑名单域名 | 不发布评论的网站域名 | 按需填写 |

## 九、常见问题

**Q：采集时提示「未找到外链数据」？**
> 请确认：1）当前页面是 SEMrush 外链分析页；2）页面数据已完全加载（表格可见）；3）已登录 SEMrush 账号

**Q：发布时提示「未找到评论区」？**
> 部分网站的评论区需要登录后才显示，或使用了特殊的评论系统（如 Disqus 需要加载完成）。可尝试：1）等待页面完全加载后点击「重新检测」；2）确认该页面确实有评论功能

**Q：发布后评论没有出现？**
> 可能原因：1）该网站评论需要审核；2）需要填写姓名/邮箱等必填项；3）触发了验证码。请手动检查页面

**Q：导入 CSV 后数据为空？**
> 请检查：1）CSV 文件编码是否为 UTF-8；2）第一行是否有列头；3）URL 列是否包含有效的网址

**Q：如何清空所有数据重新开始？**
> 进入设置页面 → 关于 → 点击「清空所有外链数据」

## 十、注意事项

⚠️ 请合理使用本插件：

- 遵守各网站的使用规则和服务条款
- 建议发布有价值的评论内容，而非纯广告链接
- 合理设置发布频率（建议间隔 2 秒以上）
- 本插件不存储任何账号密码信息
- 采集数据仅供个人 SEO 分析使用
